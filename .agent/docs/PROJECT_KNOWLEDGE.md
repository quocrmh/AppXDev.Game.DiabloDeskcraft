## 🎯 Project Overview
**Tam Quốc Deskrawl: Vô Song ARPG** (`AppXDev.Game.DiabloDeskcraft`) is a transparent Windows desktop taskbar overlay Idle Action RPG inspired by **Deskrawl: Idle ARPG** and **Diablo II: Lord of Destruction**, set in the Three Kingdoms era (*Tam Quốc Diễn Nghĩa*).

The game runs flush at the bottom of the primary display (above the Windows taskbar) in a frameless, always-on-top, click-through Electron window:
- In **Battle Mode (`215px` height strip)**, the player's warlord, escort generals, vanguard soldiers, and the Wooden Ox supply cart (*Mộc Ngưu Lưu Mã*) battle across 10 historical Three Kingdoms campaigns.
- In **Expanded Window Mode (`640px` height)**, floating Deskrawl/Diablo-styled modal windows open right above the battlefield road without pausing the live battle below.

## 🏗️ Architecture Summary
- **Runtime Shell (`electron/main.cjs`, `electron/preload.cjs`)**:
  - Frameless, transparent (`transparent: true`), always-on-top (`screen-saver` level) Electron `BrowserWindow`.
  - Dynamic mouse hit-testing (`setIgnoreMouseEvents`) so transparent sky areas pass clicks through to underlying desktop apps while HUD controls and battlefield units remain interactive.
- **Data Layer (`src/data/threeKingdomsData.js`)**:
  - **60 Famous Generals (`HEROES`)**: 15 Shu, 15 Wei, 15 Wu, 15 Qun, each with unique base stats, weapon types, pixel armor palettes, and inheritable skills.
  - **10 Historical Campaigns (`CAMPAIGN_STAGES`)**: Each stage has `wavesPerBoss: 4` (3 Sub-Boss Skulls `💀` + 1 Chief Boss Crown `👑`).
  - **6 Diablo Green Equipment Sets (`ITEM_SETS`)**: 2-piece and 4-piece bonuses with pixel ground auras.
  - **6 Skill Runes (`SKILL_RUNES`)**: Modify any of the 4 active skill slots (multi-projectile, freeze, lifesteal, chain lightning, armor break, cooldown reduction).
  - **13 Provinces (`PROVINCES_13`)**: Passive empire buffs scaled by assigned reserve general star levels.
  - **15 Combat Talents (`COMBAT_TALENTS`)**: 5 tiers (`Lv.1, 5, 10, 15, 20`) × 3 circular nodes (`0/5` ranks each).
  - **8 Historical Hero Bonds (`HERO_BONDS`)**: Permanent army-wide synergies activated when collecting historical general groups.
- **Core Game Engine (`src/engine/gameEngine.js`)**:
  - Deterministic 60fps state machine with localStorage persistence (`THREE_KINGDOMS_DESKRAWL_CLEAN_V6_2026_10_20`).
  - Handles 4-wave Boss encounters, 1v1 Single Combat Duels (*Nhất Kỵ Đương Thiên*), Random Battlefield Encounters (*Kỳ Ngộ Hành Quân*), Diablo Loot Fountain drops, Soul Shard collection (`3/3` auto-recruit), Blacksmith `+1..+15` enhancement, Affix Reforging, Set Forging, and Skull Gambling.
- **2D Pixel Art & VFX Renderer (`src/renderer/pixelOverlayRenderer.js`)**:
  - Renders parallax historical battlefields, Town Outpost NPC stalls (`inTownMode`), 4-frame horizontal sprite sheets (`sheet_*_run.png`, `sheet_*_attack.png`) with automatic background chroma-keying, Diablo vertical loot beams, stacked item nameplates, and 4-frame animated skill VFX sheets.
- **Deskrawl HUD & Floating Windows (`index.html`, `src/styles.css`, `src/main.js`)**:
  - Flush bottom-of-screen HUD with Split Red/Blue HP/Rage Globe, Potion button (`🧪 3/3`), 4 square Skill Slots, bottom-center Diablo Boss HP Bar, and bottom-right `T1–T10` 3-Skull + 1-Crown Progress Bar (`💀 💀 💀 👑`).
  - 3 iconic Deskrawl window layouts: 3-Column Minions/Generals Book, Diablo Paperdoll + 8x4 Bag Grid + Side-by-Side Comparison, and 5-Tier Circular Talent Tree.

## 🧠 Key Architectural Decisions
1. **ADR-001: Flush Bottom-of-Screen Road (`groundY = H - 20`) with Overlaid HUD Clusters** — Matches Deskrawl's exact composition so characters march on the bottom screen edge while HUD clusters sit cleanly on the left, center, and right.
2. **ADR-002: 4-Checkpoint Boss Wave Structure (`💀 ━━ 💀 ━━ 💀 ━━ 👑`)** — Eliminated tedious 10-wave trash mob grinding; every wave (1, 2, 3, 4) immediately spawns a named Sub-Boss or Stage Chief Boss on screen (`x = 477..490`).
3. **ADR-003: Automatic Sprite Background Chroma-Keying (`cleanSpriteImage`)** — Ensures all AI-generated or external sprite sheets have solid black/checkered backgrounds stripped to true alpha transparency (`alpha = 0`) on load.
4. **ADR-004: Diablo Loot Fountain with 2.2s Ground Showcase** — Boss kills fan out 2–4 equipment items + Gold Chest + Iron + Boss Soul Shard with tall vertical light beams and stacked colored labels before the Supply Cart hauls them in.
5. **ADR-005: Town Outpost Mode (`inTownMode`) with Interactive NPC Stalls** — Allows players to retreat to a peaceful outpost road and click directly on the Blacksmith, Command Altar, War Academy, or Campaign Map pavilions.

## 🐛 Known Gotchas & Troubleshooting
1. **Launching Electron from Non-Interactive Shells on Windows**:
   - Always launch via the registered Windows Scheduled Task `Start-ScheduledTask -TaskName "LaunchDiabloDeskcraft"` so Electron runs in the interactive desktop session (`Session 1`) and renders visible on the desktop.
2. **Sprite Sheet Frame Slicing**:
   - All `sheet_*_run.png` and `sheet_*_attack.png` assets are 1×4 horizontal strips (`frames = 4`). `cleanSpriteImage()` normalizes and removes dark/checkerboard backgrounds automatically.
3. **Save Key Versioning**:
   - Current save key is `THREE_KINGDOMS_DESKRAWL_CLEAN_V6_2026_10_20` in `src/engine/gameEngine.js`.
