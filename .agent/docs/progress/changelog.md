# Changelog

## [v2.0.0] — 2026-10-20 (Complete 12-Phase Deskrawl & Diablo Edition)
### Added
- **Deskrawl 4-Checkpoint Boss System (`💀 ━━ 💀 ━━ 💀 ━━ 👑`)**: Every campaign stage (`T1–T10`) features 3 Sub-Boss Generals and 1 Stage Chief Boss with a center-bottom Diablo Boss HP bar and clickable wave nodes.
- **Diablo Loot Fountain**: Bosses burst into 2–4 equipment drops + Gold Chest + Iron + Boss Skulls (`💀`) + Boss Soul Shards (`🏮`) with vertical light beams and stacked labels.
- **Town Outpost Mode (`🏕️ Doanh Trại`)**: Interactive NPC pavilions on the road (`⚒ Thợ Rèn`, `🏮 Điểm Tướng Đài`, `📕 Thái Học Viện`, `🗺️ Sa Bàn`).
- **Deskrawl Window Layouts**:
  - 3-Column Minions/Generals Showcase Book (`📜 Danh Tướng`).
  - Diablo 6-Slot Character Paperdoll + 8×3 Square Loot Grid + Side-by-Side Item Comparison (`🪖 Trang Bị`).
  - 5-Tier × 3 Circular Nodes Combat Talent Tree (`📕 Võ Kỹ & Thiên Phú`).
- **Endgame Phases 9–12**: 15 Combat Talents (`COMBAT_TALENTS`), Skull Gambling (`gambleSkullItem`), Boss Soul Shards (`heroShards`), and 8 Historical Hero Bonds (`HERO_BONDS`).
