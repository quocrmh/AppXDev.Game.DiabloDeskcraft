# Mistake Registry
| # | Mistake | Impact | Prevention |
| :--- | :--- | :--- | :--- |
| 1 | Having 10 waves of regular trash soldiers before spawning a Boss | Gameplay felt repetitive and lacked Boss presence | Keep `wavesPerBoss: 4` (`💀 💀 💀 👑`) with a named Sub-Boss or Chief Boss on every wave |
| 2 | Using `screen` blend mode on character sprites | Made characters look semi-transparent | Only use `screen` blend mode on VFX sheets (`sheet_vfx_*`), never on character sprites |
